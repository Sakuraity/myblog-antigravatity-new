看了内外这么多应用产品，有几个细节是优秀产品的共性：

1.  产品的定位是和 llm 共存，不畏惧 llm 的吞噬。

2.  在自己核心价值场景，能够做到让用户说"为什么同样的任务，我用 GPT/Claude 等 SOTA 模型做不出你们这样的效果?"

并且，用户自己折腾 prompt 等等还真就搞不出来!

3.  通过架构工程，pe，tools，skills 等设计，帮助用户突破 llm 的某些策略限制进而完成某个价值场景。

4.  没有借鉴羞耻，积极借鉴优秀设计，直接用于自己的产品。

5. 迭代快。

6. 优秀的记忆架构，让用户在心理层面产生类似依赖，兴奋，信任等长期情绪。

7. 和用户走得近，但不盲从用户的建议,敢于像用户讲述产品理念，敢于和用户说不。

8. 开放，勇于让用户的 Agent 接进来，敢于把自己的 agent 能力放出去。

9. 敢于说自己好，敢于收费。前者针对内部产品居多，后者针对商业化产品。
