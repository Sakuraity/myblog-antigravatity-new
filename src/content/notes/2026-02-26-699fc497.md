一个小经验，分享一下：

业务需要，刚刚部署了一个开源的产品数据管理产品

因为不熟悉这类的产品，打开后很懵逼

我先是让 Agent 基于代码把产品架构和 API 路由结构发给我，然后还是很懵

我就去官方看 get started 文档，看看有没有上手案例。文档写的稀烂

然后我就突然想，让agent给我做一个上手案例不就好了，用一个模拟的场景把所有的功能都串起来，至于怎么串，Agent 自己搞就好了，我也不关心

效果非常好
