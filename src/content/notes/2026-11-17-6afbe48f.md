很喜欢 Cursor 的 projects，做一些持续迭代的小开发非常方便

Cursor 这次回来使用，我觉得它很有一种气质：

Devin 非常的 ToB，有很浓烈的企业软件的感觉

Codex 处于 80 分的 ToC 感，没有让我感受到专业感哈哈

Claude Code 许久未用了，但之前的体验是90 分的工程师+tech nerd+prosumer，对普通用户会产生一些「畏惧感」

Cursor 现在体验就很 balance，60 分的工程师感，在保有严谨可信赖的基础上，也不会让一般用户感觉害怕——以及交付结果质量也很不错
